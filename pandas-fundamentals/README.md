# Pandas Data Analysis and Manipulation

A collection of Jupyter notebooks covering essential data manipulation, exploratory data analysis, and data cleaning techniques using Pandas and NumPy.

---

## Overview

* **01_Series.ipynb:** Pandas Series creation, custom indexing, vector operations, and index alignment.
* **02_DataFrames.ipynb:** 2D tabular structures, data inspection, row/column operations (.loc, .iloc), and conditional filtering.
* **03_Useful_Methods_1.ipynb:** Function application (.apply, lambda), vectorized string operations, correlations, and frequency mapping.
* **04_Useful_Methods_2.ipynb:** Handling duplicate records, range filtering (.between), and extreme value extraction (.nlargest, .nsmallest).
* **05_Missing_Values.ipynb:** Detection of NaN/NA values, row/column dropping strategies, and imputation methods.
* **06_GroupBy.ipynb:** Data segmentation and multi-level aggregation metrics.

---

## Datasets

* `tips.csv`: Restaurant tipping and customer demographics.
* `movie_scores.csv`: Pre- and post-viewing movie ratings with missing entries.
* `mpg.csv`: Automotive technical specifications and fuel economy.
